# Freya-tde Tap

## How do I install these formulae?

`brew install freya-tde/tap/<formula>`

Or `brew tap freya-tde/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "freya-tde/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
